# FleetSignal — Telematics Data Platform

**Stack:** Java 21, Spring Boot, Spring Data JPA, Python, Pandas, SQLAlchemy, MySQL 8, Flyway, JUnit 5, Testcontainers, Pytest, Docker Compose, GitHub Actions

## CV bullets

- Built a Spring Boot REST API for ingesting and querying synthetic vehicle telemetry, with MySQL persistence, Flyway migrations, range validation, pagination, time filtering, consistent errors, and OpenAPI documentation.
- Developed a Python/Pandas analytics pipeline that validates and aggregates telemetry into deterministic driver metrics, backed by JUnit, MySQL Testcontainers, Pytest, Docker Compose, and continuous-integration checks.

## LinkedIn project description

FleetSignal is a local telematics data platform that connects a Java/Spring Boot ingestion API with a Python analytics worker over a constrained MySQL schema. It demonstrates relational modeling, API validation, paginated queries, deterministic data processing, containerized development, and tests at unit, HTTP integration, and real MySQL migration boundaries.
